## 脚本运行

```
# 运行测试
npm run test
# 运行manifest检查脚本
npm run check:manifest
# 运行manifest重排序脚本
npm run sort:manifest
# 打开图形界面新增视频条目
npm run addnew
# 批量捕获视频封面
npm run cover

# 传选项时用 -- 分隔,否则选项会被 npm 当成自身配置吞掉
npm run cover -- --check
```
