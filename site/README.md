# site

基于 Nuxt 的纯前端静态站点,以竖屏全屏滑动的方式播放 `video/manifest.json` 记录的短视频

## 环境

- Node.js
- npm

## 本地开发

```
npm install
npm run dev
```

## 构建

```
npm run generate
```

静态产物位于 `.output/public`,包含站点页面与入库视频目录

## 部署基路径

站点默认部署在根路径,部署到 GitHub Pages 项目页时通过环境变量指定仓库子路径

```
NUXT_APP_BASE_URL=/<仓库名>/ npm run generate
```

## 浏览方式

- 竖屏单列全屏视频流,上下滑动切换,当前视频自动播放
- 默认静音自动播放,点击视频暂停或继续,右侧按钮开关声音
- 顶部标签切换分类,点击当前标签可回到全部
- 桌面端支持方向键或 PageUp/PageDown 切换,空格暂停,M 键静音
- 体积过大的条目只展示来源跳转,不加载视频

## 主题

- 首次访问跟随系统亮暗偏好,无偏好时使用暗色
- 页头按钮可切换亮色与暗色,选择保存在 localStorage
- 首屏由内联脚本提前应用主题,避免闪烁

## 数据来源

- 清单与标签预选项在构建期读取,站点不回写源文件
- 过大的视频目录不进入构建产物
- 标记为过大文件的条目只展示来源跳转,不加载视频
