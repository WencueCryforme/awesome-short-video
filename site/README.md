# site

基于 Nuxt 的纯前端静态站点,以竖屏全屏滑动的方式播放 `video/manifest.json` 记录的短视频

## 环境

- Node.js
- npm

## 本地开发

```
npm install
npm run dev
```

## 构建

```
npm run generate
```

静态产物位于 `.output/public`,只包含站点页面与前端资源,视频文件从对象存储读取

## 部署基路径

站点默认部署在根路径,部署到 GitHub Pages 项目页时通过环境变量指定仓库子路径

```
NUXT_APP_BASE_URL=/<仓库名>/ npm run generate
```

## 导航

- 首页: 竖屏全屏视频流,每次加载后自动打乱顺序;单击首页标签回到顶部,300ms 内再次单击重新打乱顺序,不刷新页面
- 话题: 单击展开或收起话题气泡,气泡内只展示标签名称,可多选;每行数量按标签宽度自动计算,气泡宽度贴合内容
- 话题标签双击阈值为 300ms;双击保留当前选项,回到顶部并打乱视频顺序
- 切换话题选择后重新打乱结果顺序;从话题回到首页按全部话题处理并重新打乱
- 左上三横线按钮: 打开左侧栏,内含作者、GitHub 仓库与主题开关
- URL 参数 `?topic=标签1_标签2` 临时指定话题,仅在命中标签且结果非空时生效
- 临时话题生效时隐藏侧栏入口与话题标签,首页临时展示该话题内容;参数移除后恢复
- 页面启动时主 UI 先隐藏,URL 参数解析完成后一次性显示
- 右上搜索按钮: 打开搜索页,结果两列展示封面图,点击进入视频流式详情
- 导航透明背景无边框,按钮透明且文字带轻微灰色阴影
- 视频从屏幕顶部开始,导航覆盖在视频上方,不占视频布局
- 导航宽度与主内容区一致,PC 端居中
- PC 端主 UI 区域锁定为 9:16 且高度撑满,移动端全屏

## 浏览方式

- 竖屏单列全屏视频流,上下滑动切换,当前视频自动播放,视频固定宽度并在播放区域纵向居中
- 视频区域背景固定纯黑,不随主题变化
- 视频加载出比例后,若宽大于高,向上偏移 (渲染宽度-渲染高度)/4
- 视频标题单行不换行,溢出时自动轮播: 开头停留 1 秒,正向滚动到末尾,末尾停留 1 秒,反向滚回开头,再停留 1 秒循环
- 视频第一帧加载前隐藏 video 元素,先显示封面图片,避免浏览器默认封面闪烁
- 首帧加载前显示加载中提示
- 封面图片取自构建产物内的 `cover/` 目录,与视频文件是否加载无关,不进对象存储
- 到达最后一条视频后继续尝试向下滑动时,飘窗提示“已经到底啦~”,可重复触发;仅到达末条时不提示
- 默认静音自动播放,点击视频暂停或继续,右侧按钮开关声音
- 右侧操作栏按钮顺序为静音、来源、链接、清屏
- 清屏隐藏视频区域除进度条与中央播放按钮外的 UI,切换视频不会退出清屏
- 双击视频区域或拖动/键盘调整进度后退出清屏
- 单击视频后延迟 200ms 等待双击,未形成双击才执行暂停或继续
- 视频双击超时阈值为 200ms
- 点击视频暂停或继续后有 200ms 冷却,冷却期内再次点击无效
- 暂停时的播放按钮为白底 75% 透明度,不使用毛玻璃
- 底部进度条支持拖动与键盘左右键调整播放进度
- 桌面端支持方向键或 PageUp/PageDown 切换,空格暂停,M 键静音
- 视频播放区域不展示项目作者名称

## 主题

- 默认使用亮色主题
- 左侧栏可切换亮色与暗色,选择保存在 localStorage,favicon 同步切换配色
- 视频区域固定纯黑,不随主题改变
- 话题选择不持久化,刷新页面即清空
- 首屏由内联脚本提前应用主题,避免闪烁

## 可调参数

站点自定义参数集中在 `app/const.ts`:

- `SITE`: 标题、副标题、描述、作者、仓库、版本、视频文件对象存储基地址、封面目录与封面后缀、版权年份、主题存储键
- `DEFAULT_THEME`: 默认主题
- `TOPIC_QUERY_PARAM`: URL 临时话题参数名
- `TOPIC_QUERY_SEPARATOR`: URL 多话题分隔符
- `INTERACTION`: 首页、话题与视频双击及点击冷却
- `TOAST`: 通知时长与数量
- `FEED_END_MESSAGE`: 视频流到底提示文案
- `TITLE_MARQUEE`: 标题轮播停留时长、速度与最短滚动时长
- `FEED_END_TOAST_COOLDOWN_MS`: 到底提示的重复触发冷却
- `TOPIC_BUBBLE`: 话题气泡间距、内边距与边框

## 数据来源

- 清单与标签预选项在构建期读取,站点不回写源文件
- 视频文件统一从对象存储读取,地址由 `SITE.video_oss_base_url` 提供,按 `filename` 拼接
- 封面图片在仓库 `video/cover/` 下,名为视频文件名加 `.jpg`,构建时随产物发布,站点按站点基路径拼接
- 清单条目可携带 `source_id`,用于记录来源编号
