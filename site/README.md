# site

基于 Nuxt 的纯前端静态站点,以竖屏全屏滑动的方式播放 `video/manifest.json` 记录的短视频

## 环境

- Node.js
- npm

## 本地开发

```
npm install
npm run dev
```

## 构建

```
npm run generate
```

静态产物位于 `.output/public`,包含站点页面与入库视频目录

## 部署基路径

站点默认部署在根路径,部署到 GitHub Pages 项目页时通过环境变量指定仓库子路径

```
NUXT_APP_BASE_URL=/<仓库名>/ npm run generate
```

## 导航

- 首页: 竖屏全屏视频流,每次加载后自动打乱顺序
- 话题: 点击后展开话题气泡,气泡内只展示标签名称,可多选,收起后按匹配标签数量排序并刷新视频流
- 左上三横线按钮: 打开左侧栏,内含作者、GitHub 仓库与主题开关
- 右上搜索按钮: 打开搜索页,结果两列展示并预加载封面,点击进入视频流式详情
- 导航宽度与主内容区一致,PC 端居中,不使用渐变,不覆盖视频顶部
- PC 端主 UI 区域锁定为 9:16 且高度撑满,移动端全屏

## 浏览方式

- 竖屏单列全屏视频流,上下滑动切换,当前视频自动播放
- 默认静音自动播放,点击视频暂停或继续,右侧按钮开关声音
- 右侧仅图标换源按钮可将单条视频切换为上游 iframe,播放模式仅内存保留
- 上游源播放时隐藏导航与换源外的站点 UI,滑走后恢复
- 上游 iframe 宽度贴齐主区域,上边界贴主区域顶部,固定 9:16
- 底部进度条支持拖动与键盘左右键调整播放进度
- 桌面端支持方向键或 PageUp/PageDown 切换,空格暂停,M 键静音
- 体积过大的条目只显示切换上游源的文本提示,不加载站内视频
- 视频播放区域不展示项目作者名称

## 主题

- 默认使用亮色主题
- 左侧栏可切换亮色与暗色,选择保存在 localStorage,favicon 同步切换配色
- 话题选择不持久化,刷新页面即清空
- 换源状态不持久化
- 首屏由内联脚本提前应用主题,避免闪烁

## 换源与上游源

- 每条视频默认使用站内源,点击右侧换源按钮可切换为上游 iframe
- 每条视频按 `default_mod` 选择初始源,缺失或为 `onsite` 时用站内源,`upstream` 时用上游 iframe
- `allow_iframe` 为 false 时,即使 `default_mod` 为 `upstream` 也会退化为站内源
- 抖音来源使用条目 `source_id` 直接拼装 `https://open.douyin.com/player/video?vid=<id>&autoplay=0`,其他来源按原页面嵌入
- 不请求公开 iframe 接口,iframe 由站点自建,固定 9:16 且宽度与视频区域一致
- `allow_iframe` 缺省视为 true,为 false 时点击换源提示无上游源
- 切换后从导航栏下方弹出 2 秒气泡,只保留一个,入场动画从上向下
- 上游源状态下仅保留导航与换源按钮,iframe 可直接交互
- 单条视频的播放模式只保存在内存中,刷新后恢复站内源
- 来源站可能拒绝被嵌入,画面空白时切回站内源或直接打开来源

## 数据来源

- 清单与标签预选项在构建期读取,站点不回写源文件
- 清单条目可携带 `source_id`、`allow_iframe` 与 `default_mod`,后两者分别缺省为 true 与 onsite
- `default_mod` 只决定首次进入视频时使用的源,不限制换源
- 过大的视频目录不进入构建产物
- 标记为过大文件的条目只显示切换上游源的提示,不加载站内视频
